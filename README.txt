# Jay Patharkar — Video Editor Portfolio

## Run
Open `index.html` in a browser.

For best results, use VS Code + Live Server.

## Before publishing
1. Replace `yourmail@example.com` in `index.html`.
2. Replace the `#` social links with your Instagram/WhatsApp/LinkedIn links.
3. Add future work to the Social Reels, Commercial and Motion Graphics cards.
4. Compress videos if the deployed site becomes slow.
